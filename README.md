# DIY Media Cyberdeck 🎧

My first attempt at building a portable cyberdeck designed for music and video playback.

## Version 1 — Wokwi Prototype

The first prototype was built in Wokwi using an Arduino Uno.

### Components

- Arduino Uno
- SSD1306 OLED display
- 4 push buttons

### Current Features

- OLED menu interface
- Menu navigation
- Up/down controls

### Controls

| Button | Function |
|---|---|
| Button 1 | Up |
| Button 2 | Down |
| Button 3 | Select |
| Button 4 | Back |
